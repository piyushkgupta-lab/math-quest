# 🧠⚡ Math Quest

A fun, arcade-style math game for Grade 7 students. Built with HTML, CSS, and JavaScript.

**Topics covered:** Integers, Fractions, Percentages, Decimals, Pre-Algebra, Geometry

**Features:**
- 🔥 Streak system with bonus XP
- ⏱️ No timer per question
- 📈 XP & leveling system
- 🔊 Sound effects
- 💾 Progress saved automatically
- 📱 Works on phones as a PWA (Add to Home Screen)
